# مشروع موقع وكالة سفر وحج وعمرة

وصف
----

هذا المستودع يحتوي على نسخة مشروع موقع إلكتروني لوكالة سفر متكاملة للحج والعمرة والرحلات. الموقع مصمّم لعرض الباقات، إدارة الحجوزات أونلاين، جمع بيانات العملاء، وإمكانية البيع الإلكتروني وخدمات إضافية.

الميزات الرئيسية
-----------------

- صفحات عرض باقات (حج، عمرة، رحلات داخلية وخارجية) مع صور ووصف وأسعار.
- نظام حجز إلكتروني وإدارة المقاعد والبرامج.
- بوابات دفع إلكتروني قابلة للتكامل.
- لوحة إدارة (CMS) لتحديث البرامج والأسعار والصور بسرعة.
- جمع وتصدير بيانات العملاء للتسويق والمتابعة.
- متجر إلكتروني للخدمات والمنتجات الإضافية.
- تكامل دردشة واتساب أو شات مباشر للرد السريع.
- دعم تعدد اللغات حسب الحاجة.
- تحسين أساسيات SEO وتجربة مستخدم متوافقة مع الهواتف.

معاينة
-------

أضف لقطات شاشة هنا أو رابط المعاينة: https://el-riyad-travel.onrender.com

المتطلبات (Prerequisites)
-------------------------

- Node.js >= 14 (إذا كان المشروع مبنياً على Node) أو حسب التقنية المستخدمة.
- Git
- مدير الحزم npm أو yarn
- قواعد بيانات (MySQL, PostgreSQL, MongoDB) حسب الإعدادات إن وُجدت.

التشغيل محلياً (مثال عام)
-------------------------

1. استنساخ المستودع:

```bash
git clone https://github.com/Ashref2004/-.git
cd -
```

2. تثبيت الاعتمادات:

```bash
npm install
# أو
# yarn install
```

3. نسخ ملف المتغيرات البيئية وإنشاء القيم المطلوبة:

```bash
cp .env.example .env
# ثم حرّر .env واملأ المتغيرات مثل قواعد البيانات ومفاتيح الدفع
```

4. تشغيل المشروع:

```bash
npm run dev
# أو
# npm start
```

5. فتح المتصفح على: http://localhost:3000 (أو البورت المحدد في .env)

ملاحظات تهيئة ونشر
------------------

- يفضّل إعداد متغيرات البيئة (API_KEYS, DATABASE_URL, PAYMENT_GATEWAY_KEYS) في بيئة آمنة.
- للاستضافة الإنتاجية يُنصح باستخدام خدمات مثل Render, Vercel, DigitalOcean أو استضافة مدفوعة تعتمد على حركة المرور.
- تأكد من تفعيل شهادة SSL وحماية خطوط الاتصال.

هيكل المجلدات (مثال)
---------------------

- /src — كود التطبيق
- /public — ملفات ثابتة (صور، css، js)
- /config — إعدادات وقيم بيئية
- /scripts — أدوات مساعدة
