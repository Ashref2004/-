# 🌙 موقع يوم عرفة المبارك

موقع تفاعلي مصمم خصيصًا ليوم عرفة، يحتوي على الأدعية المأثورة، الأحاديث النبوية، الآيات القرآنية، فضائل اليوم، وأوقات الصلاة حسب الموقع الجغرافي، بالإضافة إلى عدّ تنازلي لبدء يوم عرفة وتشغيل صوتيات.

## 📜 المميزات
- 🕌 **الأدعية المأثورة** الخاصة بيوم عرفة.
- 📖 **أحاديث نبوية** حول فضل اليوم.
- 📜 **آيات قرآنية** تتعلق بالحج ويوم عرفة.
- ⭐ **فضائل وأعمال يوم عرفة**.
- ⏳ **عدّ تنازلي** لبداية يوم عرفة.
- 🕋 **أوقات الصلاة حسب موقع المستخدم** (باستخدام [Aladhan Prayer Times API](https://aladhan.com/prayer-times-api)).
- 🎵 **تشغيل صوتيات** بضغطة زر.
- 🎨 **تصميم عصري ومتجاوب** مع مؤثرات جمالية.

## 🛠️ التقنيات المستخدمة
- **HTML5** و **CSS3** مع تصميم متجاوب (Responsive Design).
- **JavaScript** للتفاعل مع المحتوى.
- مكتبة **Font Awesome** للأيقونات.
- خط **Tajawal** من Google Fonts.
- **Aladhan Prayer Times API** لجلب مواقيت الصلاة.

## 📂 هيكل الملفات
```
project/
│── index.html       # الصفحة الرئيسية
│── style.css        # تنسيقات الموقع
│── script.js        # وظائف JavaScript
```

## 🚀 طريقة التشغيل
1. استنسخ المشروع إلى جهازك:
   ```bash
   git clone https://github.com/Ashref2004/-.git
   ```
2. افتح الملف `index.html` في المتصفح.
3. تأكد من اتصالك بالإنترنت لجلب الخطوط والأيقونات وبيانات أوقات الصلاة.
