# يوم عرفة المبارك — واجهة HTML/CSS/JS

وصف
----

هذا الملف README خاص بالملف الواحد الموجود في المستودع: واجهة ثابتة تحتوي على صفحة HTML (عرض "يوم عرفة المبارك") مع كود JavaScript وملف CSS مصاحب. التصميم باللغة العربية (اتّجاه النص من اليمين إلى اليسار) ويعرض أدعية، أقوال نبوية، آيات، فضائل اليوم، وحساب توقيتات الصلاة باستخدام واجهة API خارجية.

الملفات المقترحة
-----------------

- index.html — ملف الصفحة الرئيسي (محتوى HTML الذي زوّدت به).
- style.css — ملف أنماط CSS (محتوى CSS الموجود في المقطع).
- script.js — ملف جافاسكربت (المقطع البرمجي الذي يتضمن التبديل بين التبويبات، العدّ التنازلي، تشغيل الصوت، واستدعاء API لأوقات الصلاة).

كيفية الاستخدام محلياً
----------------------

1. انسخ أو احفظ المحتويات في ثلاثة ملفات داخل مجلد واحد:
   - index.html
   - style.css
   - script.js

2. افتح المشروع عبر خادم محلي (مفضّل) لأن بعض طلبات الـ API وميزات الصوت والموقع قد لا تعمل من ملف file://. أمثلة سريعة:

   - باستخدام Live Server في VS Code: افتح المجلد ثم "Open with Live Server".
   - أو باستخدام Python (إذا مثبت):

     ```bash
     python -m http.server 8000
     # ثم افتح http://localhost:8000
     ```

3. افتح المتصفح إلى http://localhost:8000 أو المسار الذي استخدمته.

ملاحظات فنية مهمة
-----------------

- أوقات الصلاة تُستدعى عبر API: https://api.aladhan.com. لعمل الاستدعاء بنجاح في بعض المتصفحات يجب تشغيل الصفحة عبر HTTPS أو خادم محلي.
- ميزة تحديد الموقع (Geolocation) تطلب إذن المستخدم؛ في حال رفض الإذن سيتم عرض رسالة واستعمال قيم افتراضية (كما في الكود).
- ملف الصوت يُحمّل من رابط خارجي (SoundHelix). تأكد من قبول المتصفح لتشغيل الصوت أو استخدام رابط صوتي خاص بك.
- تاريخ يوم عرفة مضبوط في الكود على: June 15 (يمكنك تغييره حسب التقويم الهجري/الميلادي في بلدك).
- خط Google Tajawal وFontAwesome مستعملان عبر CDN — يتطلّب اتصال إنترنت لعرضهما.

كيف أعدّل النصوص
-----------------

- لتعديل المحتوى (أدعية، آيات، نصوص) حرّر index.html وعدّل النصوص داخل العناصر المناسبة.
- لتغيير الألوان والتصميم حرّر style.css.
- لتعديل منطق العدّ التنازلي أو استدعاءات API حرّر script.js.

اقتراحات تحسين مستقبلية
-----------------------

- فصل الملفات إلى مجلد src/ أو assets/ مع أمثلة صور.
- إضافة ملف .env.example لتخزين مفاتيح API إن لزم.
- تحسين دعم التاريخ الهجري باستخدام مكتبة تقويم هجري إذا أردت دقة أكبر لليوم.
- إضافة اختبارات وصولية (accessibility) وتحسين تباين الألوان للقراءة.
